# ProLevelThinker Website

Official website for **ProLevelThinker** — Web Design, Development & Digital Marketing services for ambitious businesses in Bangladesh.

**Live site (once deployed):** https://souravsuvro.github.io/prolevelthinker-website/  
**GitHub:** https://github.com/Souravsuvro/prolevelthinker-website

## Features

- Responsive, mobile-first design
- Modern UI with CSS custom properties and smooth animations
- Sections: Hero, Services, Process, Portfolio (filterable), Pricing, Insights, Contact form
- Accessibility: skip link, ARIA labels, focus states, reduced-motion support
- SEO-ready: meta tags, Open Graph, JSON-LD schema
- Multi-page structure for services, portfolio items, insights, legal pages

## Tech Stack

- Pure HTML5, CSS3, vanilla JavaScript
- No frameworks required (easy to host on GitHub Pages, Netlify, Vercel, or any static host)

## Local Development

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python -m http.server 8080
```

## Deployment

This repository is ready for **GitHub Pages**:

1. Go to Settings → Pages
2. Source: Deploy from a branch → `main` / root
3. Your site will be available at `https://souravsuvro.github.io/prolevelthinker-website/`

Alternatively deploy to Vercel, Netlify, or Cloudflare Pages with zero config.
